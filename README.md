# 💰 Expense Tracker Dashboard

A modern web application built with Flask that helps users manage their personal finances.

Users can:

- Register an account
- Login securely
- Add income
- Add expenses
- Edit transactions
- Delete transactions
- Search transactions
- Filter by month
- View financial reports
- Export CSV reports
- View interactive charts
- Switch between Light and Dark Mode

## Installation

Clone the repository

```bash
git clone https://github.com/YourUsername/ExpenseTracker.git
```

Move into the folder

```bash
cd ExpenseTracker
```

Install requirements

```bash
pip install -r requirements.txt
```

Run

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
